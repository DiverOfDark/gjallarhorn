# Workloads

Deployments, StatefulSets, DaemonSets, CronJobs, Jobs and bare Pods, each with the images it runs. Columns: findings in its images by severity, failed configuration checks and secrets found.

Filter by namespace or by text: name, kind or image. The namespace links on the overview open this page filtered to one namespace.

A workload's vulnerability counts add up its distinct images, so two containers with the same image count once.
